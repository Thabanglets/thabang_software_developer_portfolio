# Thabang Letsoalo — Portfolio Website

A responsive multi-page portfolio website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home / introduction
- `about.html` — About me
- `projects.html` — Selected projects
- `skills.html` — Skills and tools
- `resume.html` — Education, project experience and print-to-PDF resume
- `contact.html` — Contact form that opens the visitor's email application

## Run locally
1. Extract the ZIP file.
2. Open the `thabang_portfolio` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Personalise before publishing
1. In `contact.html`, replace `your.email@example.com`, `github.com/yourusername` and `linkedin.com/in/yourprofile`.
2. In `assets/script.js`, replace the `recipient` value with your real email address.
3. Update the education institution, study dates, certifications and project links with accurate details.
4. Adjust project descriptions and skill levels so they reflect your current work.

No backend is included. The contact form uses a `mailto:` link, so it opens the visitor's configured email application.
